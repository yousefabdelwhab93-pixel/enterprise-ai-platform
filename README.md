
# Enterprise AI Knowledge & Support Platform

A bilingual, multi-tenant AI platform for enterprise knowledge retrieval and intelligent customer support automation.

## Project Overview

The platform enables organizations to:

- Search and retrieve information from internal documents.
- Ask questions in Arabic and English.
- Get AI-generated answers with source citations.
- Classify and route customer support tickets.
- Generate suggested responses for human review.
- Monitor AI quality, latency, and cost.

## Tech Stack

- Backend: Python, FastAPI
- Frontend: React, TypeScript
- Database: PostgreSQL
- Vector Database: Milvus
- Embeddings: Jina
- AI Orchestration: LangChain, LangGraph
- Evaluation: RAGAS
- Monitoring: Langfuse
- Infrastructure: Docker

## Project Status

Currently in the initial setup and foundation phase.
